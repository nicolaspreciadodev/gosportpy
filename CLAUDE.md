# GoSport - Backend Configuration

## Desarrollo Local
- Levantar Servidor: `python manage.py runserver` o `flask run`
- Entorno Virtual: Asegurarse de activar el `.venv` antes de ejecutar comandos.

## Calidad de Código y Estándares
- Seguir estrictamente las guías de estilo de **PEP 8**.
- Implementar y verificar pruebas de QA (Quality Assurance) antes de consolidar cambios.
- Mantener la arquitectura limpia y modular en los controladores/vistas del backend.
